# Governed ChatGPT Skills

A deliberately small collection of reusable ChatGPT skills promoted from reviewed canonical sources.

## Governed Work Starter Pack

The initial release sequence is:

1. **Governed PRD Creation** — define measurable product intent before architecture or implementation.
2. **Session Handoff Compact** — preserve verified context when work moves to a new conversation or operator.
3. **Governed Excel Creation** — create and repair controlled business workbooks with validation and lineage.

No skill is considered released merely because a branch, ZIP archive, or draft pull request exists.

## Source and release model

- The private canonical repository is `deldos/skills`.
- This public repository is a downstream publishing surface.
- Every public skill must identify its canonical path, version, reviewed source commit, public pull request, and release evidence.
- Public defects are repaired in the canonical source first, then promoted downstream.
- Connector-dependent behavior must be optional or abstracted so public skills remain understandable and usable outside the private operating environment.

Read [GOVERNANCE.md](GOVERNANCE.md) and [PUBLICATION_WORKFLOW.md](PUBLICATION_WORKFLOW.md) before contributing.
